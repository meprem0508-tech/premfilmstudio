# 🎬 PREM FILM STUDIOS

## Where Creativity Meets Cinema

PREM FILM STUDIOS is a cinematic creative platform concept designed to discover,
support and showcase emerging filmmakers, actors, writers, directors, editors,
musicians, VFX artists, content creators and storytellers.

---

## Website Features

- Cinematic opening screen
- Dark cinematic interface
- Film grain
- Smoke atmosphere
- Glass / water UI
- Animated navigation
- Home page
- Creator portrait
- Film AI Assistant
- Voice recognition
- Text-to-speech
- About page
- Creative journey
- Creator categories
- Contact page
- QR code
- Email contact
- Mobile responsive design

## Important

The Film AI Assistant included in this version is a browser-based
filmmaking assistant using JavaScript knowledge and browser speech APIs.

It does not require an API key.

A future version can connect to a real AI backend.
